# LAHEE HOME

React 기반 스마트홈 프론트엔드 시뮬레이터입니다.

## 실행

```bash
npm install
npm run dev
```

## 현재 범위

- 2D 홈 평면도 및 방 입장 인터랙션
- 방별 조명, 에어컨, 청소기 등 기기 상태 제어
- 사용자 활동 및 센서 이벤트 mock 시뮬레이션
- WebSocket 연결 상태와 실시간 mock 이벤트 반영
- 에이전트 간 A2A 메시지 로그 시각화
- 예측 결과 및 실행 과정 대시보드

실제 WebSocket 서버와 에이전트 API는 후속 백엔드 단계에서 연결하도록 분리되어 있습니다.
